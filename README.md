# 📌 Descripción del proyecto

**Entre Uvas y Café** es una aplicación web desarrollada para una cafetería, diseñada para ofrecer una experiencia moderna, intuitiva y completamente responsive.

El sitio permite a los usuarios conocer la cafetería, explorar sus productos y acceder a información relevante mediante una interfaz atractiva y optimizada para distintos dispositivos.

Además, incorpora un **panel de administración protegido mediante Firebase Authentication**, desde el cual es posible administrar el contenido del sitio y almacenar imágenes utilizando **Firebase Storage**, permitiendo actualizar la información sin modificar el código fuente.

# 🚀 Funcionalidades

## 🌐 Sitio público

- 🏠 Página de inicio con presentación de la cafetería.
- ☕ Catálogo de productos.
- 🖼️ Galería de imágenes.
- 📍 Información de contacto y ubicación.
- 📱 Diseño totalmente responsive.

## 🔐 Panel de Administración

- Inicio de sesión mediante **Firebase Authentication**.
- Acceso restringido únicamente a administradores autorizados.
- Gestión del contenido desde un panel privado.
- Carga y actualización de imágenes utilizando **Firebase Storage**.
- Administración sencilla sin necesidad de modificar el código.

# ⚙️ Instalación

Clonar el repositorio

```bash
git clone https://github.com/henryguajard/EntreUvas_Cafe.git
```

Ingresar al proyecto

```bash
cd EntreUvas_Cafe
```

Abrir el proyecto con **Visual Studio Code**.

Si utilizas la extensión **Live Server**, inicia el servidor desde `index.html`.
